# Breizh & Beyond

Cria um website COMPLETAMENTE NOVO, DO ZERO, para a marca gastronómica **BREIZH FOOD**.



IMPORTANTE:



* Assume que não existe qualquer website anterior.

* Não copies nem reutilizes qualquer design, estrutura ou layout de outro projeto.

* Não partas de um template genérico de restaurante.

* Cria toda a identidade visual, estrutura, componentes, animações e experiência de utilizador de raiz.

* Quero um resultado de nível profissional, como se tivesse sido criado por um estúdio francês especializado em branding, web design e motion design.



# CONCEITO DA MARCA



Nome:



**BREIZH FOOD**



Conceito:



Uma marca gastronómica inspirada na Bretanha francesa, com ligação a Portugal.



Direção artística:



**CHIC FRANCÊS + LUXO DISCRETO + BRETANHA + MADEIRA NATURAL + GASTRONOMIA PREMIUM**



Quero uma mistura entre:



* maison française contemporânea

* restaurante francês premium

* épicerie francesa sofisticada

* gastronomia artesanal

* street food gourmet

* design editorial francês

* materiais naturais

* madeira nobre

* detalhes champagne gold



A sensação geral deve ser:



**elegante + francesa + sofisticada + artesanal + moderna + acolhedora + premium.**



Não quero algo antiquado.



Quero uma interpretação contemporânea do luxo francês.



---



# IDENTIDADE VISUAL



Criar uma identidade visual completamente nova para a BREIZH FOOD.



A marca deve parecer real, estabelecida e premium.



Não quero aparência de template.



O website deve ter personalidade própria.



A estética deve lembrar uma marca gastronómica francesa contemporânea que poderia existir numa zona elegante de Paris, mas mantendo a alma da Bretanha.



---

# INTRO / PAGE LOAD



Criar uma pequena introdução cinematográfica.



Ao abrir:



1. fundo aparece;

2. pequena linha champagne/dourada surge;

3. BREIZH FOOD aparece elegantemente;

4. a linha expande;

5. o título principal é revelado;

6. a fotografia aparece através de uma máscara;

7. restantes elementos entram em stagger.



A animação deve ser curta.



Não criar loading screen demorado.



O website deve ficar rapidamente utilizável.



Respeitar `prefers-reduced-motion`.



---



# MOTION DESIGN



ESTA É UMA PRIORIDADE ABSOLUTA.



Quero motion design elaborado, premium, moderno e extremamente suave.



Não quero apenas fades básicos.



Criar uma experiência semelhante aos websites de estúdios criativos franceses premium.



Utilizar:



* staggered typography

* text reveal

* clip-path reveals

* image masking

* smooth parallax

* subtle image zoom

* scale transitions

* scroll-triggered animations

* animated lines

* typography movement

* horizontal transitions

* section reveals

* sophisticated hover states

* magnetic buttons muito subtis

* microinteractions

* transições cinematográficas entre secções



As animações devem parecer cuidadosamente coreografadas.



Utilizar easing natural e sofisticado.



Evitar completamente:



* bounce

* elastic exagerado

* elementos a saltar

* rotações aleatórias

* efeitos infantis

* excesso de blur

* animações demasiado lentas

* efeitos "template"

* movimentos excessivos



Objetivo:



**"Uau, este site tem motion design incrível."**



mas sem sacrificar elegância ou performance.



---
